## From the first workshop to production

I've built software professionally since 2015. At COBOX Technologies, I lead engineering teams and work directly with customers. I start by mapping how their teams work, then turn those findings into a shared plan for product design, implementation, and rollout.

| Where I work | What I build |
| --- | --- |
| **Backend architecture** | APIs, data models, and integrations with Laravel, Node.js, Python, and .NET |
| **Product engineering** | Web and mobile software built around the workflows people use every day |
| **Technical delivery** | Deployment pipelines, automated tests, and monitoring for production releases |
| **Automation and data** | Workflow automation, AI features connected to business data, and reporting dashboards |
